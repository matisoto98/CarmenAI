# ADR-011: Propiedades de calidad como baterías de prueba

- Estado: Aceptado
- Origen: v1.0 (reconstruido)
- Referencia: Documento Maestro v4.8, sección 10.3, 10.5

> Reconstruido en la v4.8 a partir de la matriz de trazabilidad (15.12). El texto original de la v1.0 no está en el paquete de entrega; si aparece, sustituye a este. La numeración 001 a 012 también es reconstruida, salvo ADR-010, que el documento cita expresamente (6.10.6).

## Contexto

Un sistema no determinista no se puede validar solo con pruebas de ejemplo.

## Decisión

La calidad se expresa como baterías de propiedades (10.5).

## Consecuencias

Se integran como capa 8 de la estrategia de pruebas por capas.
