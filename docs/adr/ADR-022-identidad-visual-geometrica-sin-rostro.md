# ADR-022: Identidad visual geométrica, sin rostro

- Estado: Aceptado
- Origen: v2.2
- Referencia: Documento Maestro v4.8, sección 5.12

## Contexto

La identidad ilustrada anterior (cara, PNG de 1,6 MB) presentaba a Carmen como un personaje.

## Decisión

Carmen se representa con un símbolo vectorial geométrico, sin cara, ojos ni rasgos: es la imagen de IT, no un personaje. El logo es estático siempre; el movimiento vive en carmen-thinking.svg.

## Consecuencias

Las pruebas de 5.12 protegen el símbolo, la palabra y el indicador.
