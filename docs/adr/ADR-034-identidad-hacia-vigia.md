# ADR-034: Identidad hacia VigIA

- Estado: RESERVADO
- Origen: v4.2
- Referencia: Documento Maestro v4.8, sección 7.8.1

## Contexto

Pendiente P11: audiencia y scope de la API del MCP de VigIA en Entra ID y consentimiento on-behalf-of para la aplicación de Carmen.

## Decisión

Se decide con el informe del Prompt 10.

## Consecuencias

Bloquea el uso de VigIA desde el servidor de Carmen y la certificación de agent.vigia.
